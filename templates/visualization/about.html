About DD3S

Project Overview

DD3S is a comprehensive molecular database and analysis platform that combines:

  • 3D Molecular Visualization - Interactive structure viewing
  • AI/ML Predictions - Neural network-based property predictions
  • RCSB PDB Integration - Direct access to protein data bank
  • SMILES Processing - Chemical structure analysis

Features

User Features
  • Search molecules by name, formula, or properties
  • View 3D molecular structures
  • Predict toxicity, solubility, and activity
  • Export data for research
Admin Features
  • User activity logging
  • Search analytics
  • Prediction tracking
  • Full database management

Technology Stack

  • Backend: Django 6.0, Django REST Framework
  • AI/ML: PyTorch, Transformers (ChemBERTa), RDKit
  • Visualization: 3Dmol.js, Plotly
  • API: RCSB PDB API (rcsbapi)
  • Security: 2FA, Email Verification
